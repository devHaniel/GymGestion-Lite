# 📋 Código de Conducta

## Nuestro Compromiso

**GymGestion-Lite** se compromete a proporcionar un ambiente profesional, seguro y respetable para todos.

---

## Nuestros Estándares

### Comportamiento Esperado:

✅ Ser respetuoso en toda comunicación  
✅ Ser profesional en reportes y sugerencias  
✅ Reconocer las limitaciones del software  
✅ Reportar problemas de manera constructiva  
✅ Respetar la privacidad y confidencialidad  

### Comportamiento No Aceptable:

❌ Lenguaje abusivo, grosero u ofensivo  
❌ Acoso o discriminación de cualquier tipo  
❌ Intentos de vulnerar seguridad  
❌ Compartir código de manera no autorizada  
❌ Actividades ilegales o fraudulentas  
❌ Spam o comunicaciones masivas no solicitadas  

---

## Reportar Incidentes

Si presencias comportamiento inapropiado:

1. **Documentar el incidente:**
   - Fecha y hora
   - Descripción del comportamiento
   - Personas involucradas
   - Impacto causado

2. **Reportar a:**
   ```
   Email: [tu-email@ejemplo.com]
   Asunto: [INCIDENTE] Descripción breve
   Marcar como confidencial si es necesario
   ```

3. **Investigación:**
   - Se investigará de manera confidencial
   - Se tomarán acciones apropiadas
   - Se notificará al reportante sobre resultado

## Cumplimiento

### Consecuencias del Incumplimiento:

- **Advertencia:** Recordatorio de este código
- **Restricción:** Limitación de acceso o comunicación
- **Expulsión:** Cancelación de licencia o acceso
- **Legal:** Acciones legales si corresponde

## Ejemplo de Comunicación Profesional

### ❌ Incorrecto:

> "Tu software es basura y no funciona. Los desarrolladores son incompetentes."

### ✅ Correcto:

> "He encontrado que el módulo de reportes genera errores con ciertos formatos de fecha. He reproducido el problema con la fecha 31/02/2024. ¿Pueden revisar esto?"

---

## Políticas Específicas

### 1. Para Reportes de Bugs

- Ser específico y reproducible
- Proporcionar pasos claros
- No incluir datos reales de clientes
- No ser agresivo si no hay respuesta inmediata

### 2. Para Sugerencias de Mejora

- Explicar claramente el beneficio
- Reconocer limitaciones del software
- Proponer soluciones constructivas
- Ser paciente con el proceso de evaluación

### 3. Para Discusiones Técnicas

- Mantener tono profesional
- Estar abierto a diferentes perspectivas
- Reconocer expertise de otros
- Contribuir con conocimiento, no crítica

---

## Privacidad y Datos

### Obligaciones:

- Nunca compartir datos de clientes públicamente
- Proteger información confidencial
- Cumplir con leyes de protección de datos
- Notificar sobre posibles brechas de seguridad

### Consecuencias:

Violaciones graves de privacidad pueden resultar en:
- Cancelación inmediata de licencia
- Acciones legales
- Reportes a autoridades competentes

---

## Resolución de Conflictos

### Nivel 1: Comunicación Directa
Contactar directamente con el responsable

### Nivel 2: Escalación
Si no se resuelve, escalalar a soporte técnico

### Nivel 3: Mediación
Facilitar diálogo constructivo para resolver

### Nivel 4: Decisión Final
Determinar acciones apropiadas
