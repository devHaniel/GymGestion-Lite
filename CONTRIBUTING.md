## 🚀 Para Desarrolladores Autorizados

Si tienes acceso al repositorio privado:

### Flujo de Trabajo

1. **Clonar repositorio**
   ```bash
   git clone [url-privada]
   ```

2. **Crear rama de feature**
   ```bash
   git checkout -b feature/nombre-funcionalidad
   ```

3. **Hacer cambios y commitear**
   ```bash
   git add .
   git commit -m "Descripción clara del cambio"
   ```

4. **Push a rama**
   ```bash
   git push origin feature/nombre-funcionalidad
   ```

5. **Crear Pull Request para revisión**

### Estándares de Código

- **Nombrado:** `PascalCase` para clases, `camelCase` para variables
- **Documentación:** Agregar comentarios en código complejo
- **Testing:** Verificar cambios en ambiente local
- **Seguridad:** NO commitear credenciales o contraseñas

## 📋 Convenios de Commit

Usar formato: `[TIPO] Descripción corta`

Tipos válidos:
- `[FEAT]` - Nueva funcionalidad
- `[FIX]` - Corrección de bug
- `[DOCS]` - Cambios en documentación
- `[STYLE]` - Formato de código
- `[REFACTOR]` - Reorganización sin cambiar funcionalidad
- `[PERF]` - Mejoras de performance
- `[TEST]` - Cambios en pruebas
- `[CHORE]` - Tareas de mantenimiento

**Ejemplos válidos:**
```
[FEAT] Agregar reporte mensual de ventas
[FIX] Corregir error en cálculo de impuestos
[DOCS] Actualizar guía de instalación
```
